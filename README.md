# Statio NFC Deneme

Statio projesinin M0 saha testi için tek sayfalık Web NFC deneme aracı. Android'de Chrome ile açılır.

Sayfa: https://ulutanbarlas.github.io/statio-nfc-test/

- Etiket okur (seri no + NDEF içerik), deneme koşullarını kaydeder, etikete link/metin yazar (kilitlemez), sonuçları CSV olarak indirir.
- Hiçbir veri sunucuya gönderilmez; kayıtlar yalnız telefonun tarayıcısında tutulur.
